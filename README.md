Customer Shopping Behaviour Analysis

Project Overview

This project explores customer shopping behaviour and presents insights through data analysis and visualization. It is a hands-on learning project completed by following a guided tutorial to gain practical experience with Python, PostgreSQL, and Power BI.

Tools & Technologies

- Python – Data analysis and preprocessing
- Pandas – Data manipulation and cleaning
- PostgreSQL – Database management and SQL queries
- Power BI – Interactive dashboard and data visualization
- Jupyter Notebook – Python development environment

Project Workflow

1. Data Exploration
   
   - Loaded and explored the customer shopping dataset.
   - Examined data structure and column information.

2. Data Cleaning & Preparation
   
   - Handled missing values.
   - Standardized column names.
   - Created additional features such as age groups and purchase frequency intervals.

3. Database Integration
   
   - Connected Python with PostgreSQL.
   - Loaded the prepared dataset into the database.

4. Data Visualization
   
   - Developed an interactive Power BI dashboard.
   - Presented customer shopping behaviour through visual reports.

Project Files

File| Description
"Customer_Shopping_Behaviour_Analysis.ipynb"| Python analysis notebook
"Customer_Behavior_Dashboard.pbix"| Power BI dashboard

How to Explore This Project

1. Download or clone this repository.
2. Open the ".ipynb" file using Jupyter Notebook.
3. Install the required Python libraries, including Pandas.
4. Configure PostgreSQL connection details if you want to reproduce the database integration.
5. Open the ".pbix" file using Power BI Desktop to explore the dashboard.

- Gained experience working with Pandas.
- Practiced connecting Python with PostgreSQL.
